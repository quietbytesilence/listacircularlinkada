# Lista Circular Simplesmente Encadeada Não Ordenada

Este projeto implementa uma lista circular simplesmente encadeada não ordenada em Python. A lista permite a adição de elementos no início e no fim, remoção de elementos por valor, exibição da lista e esvaziamento completo da lista. Além disso, o projeto inclui um menu interativo para facilitar a manipulação da lista.

## Funcionalidades

- **Adicionar no início**: Adiciona um novo elemento no início da lista.
- **Adicionar no fim**: Adiciona um novo elemento no fim da lista.
- **Remover elemento por valor**: Remove todos os elementos que possuem o valor especificado.
- **Esvaziar lista**: Remove todos os elementos da lista.
- **Exibir lista**: Exibe todos os elementos da lista, mostrando o endereço de memória, o valor e o endereço do próximo nó.

## Como Usar

### Pré-requisitos

- Python 3.x instalado.

### Instalação

1. Clone o repositório:

   ```bash
   git clone https://github.com/quietbytesilence/listacircularlinkada.git
   ```

2. Navegue até o diretório do projeto:

   ```bash
   cd listacircularlinkada
   ```

### Executando o Projeto

1. Execute o script `Script.py`:

   ```bash
   python Script.py
   ```

2. Siga as instruções no menu interativo para manipular a lista circular.

### Exemplo de Uso

1. **Adicionar elementos**:
   - Escolha a opção `1` para adicionar no fim ou `2` para adicionar no início.
   - Digite o valor que deseja adicionar.

2. **Remover elementos**:
   - Escolha a opção `4`.
   - Digite o valor que deseja remover.

3. **Exibir lista**:
   - Escolha a opção `3` para exibir todos os elementos da lista.

4. **Esvaziar lista**:
   - Escolha a opção `5` para esvaziar a lista completamente.

5. **Sair**:
   - Escolha a opção `6` para sair do programa.

## Estrutura do Projeto

- `listas_feitas_com_listas.py`: Contém uma implementação básica de uma lista usando a estrutura de lista do Python, com funções para adicionar, remover e exibir elementos.
- `Script.py`: Contém a implementação da lista circular simplesmente encadeada não ordenada, com um menu interativo para manipulação da lista.
